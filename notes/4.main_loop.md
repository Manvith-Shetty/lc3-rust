But before that, does the vm memory contain the program? Coz we need to get the obj from file in disk to vm memory and pc points to first instruction. In LC obj files the first line is always 0x3000 which is assembler's .ORIG directive and it means "place everything that follows starting at memory address 0x3000" (This we have already hardcoded in our program 0x3000)
This is like a metadata for the program.
